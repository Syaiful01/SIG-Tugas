Resep Kode Siap Pakai

Salin, tempel, jalankan.

1 · Inisialisasi Peta
const map = L.map('map', {
  center: [3.5952, 98.6722],
  zoom: 12
});
L.tileLayer(
  'https://{s}.tile.openstreetmap.org/{z}/{x}/{y}.png',
  { maxZoom: 19, attribution: '© OSM' }
).addTo(map);
2 · Marker + Popup
L.marker([3.5750, 98.6839])
  .addTo(map)
  .bindPopup('<h4>Istana Maimun</h4>')
  .openPopup();
